# VELUNE · AI Atelier

Добавлена секция AI Atelier: повод, палитра, бюджет 3 900–20 000 ₽, пожелания, текстовая концепция, копирование запроса для флориста и ссылка на Telegram.

## Как запустить

1. В папке проекта выполнить `npm install` и `npm run dev`.
2. Для настоящей генерации с ИИ развернуть проект на Vercel и добавить **серверную** переменную окружения `OPENAI_API_KEY` (в Vercel → Settings → Environment Variables). При желании указать `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`). Повторно развернуть проект.
3. Telegram магазина задаётся переменной `VITE_TELEGRAM_USERNAME` без `@`. Сейчас по умолчанию указан `theaminasoul` из исходного сайта: обязательно проверить правильность аккаунта перед запуском.
4. Если серверная функция или API недоступны, конструктор показывает **шаблонную** концепцию с честной пометкой, а не выдает её за ответ ИИ.
5. В текущем MVP нет оплаты, автосоздания заказа, генерации изображения букета и проверки складских остатков. Для реального запуска эти функции нужно разработать отдельно.
6. Для публичного масштабного запуска: rate limiting, защита от злоупотреблений, мониторинг расходов API, уведомление об обработке данных и согласование политики конфиденциальности.

## Файлы

- `src/components/AIAtelier.css` — стили

## Безопасность заказа

Итоговая цена и состав подтверждаются флористом. При нажатии «Скопировать заявку» текст копируется в буфер; клиент должен сам отправить его в Telegram. Сайт не утверждает, что заказ автоматически оформлен.
