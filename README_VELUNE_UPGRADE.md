# VELUNE — улучшенная версия сайта

Изменения:
- Новая витрина трёх коллекций: ÉPURE (от 3 900 ₽), SIGNATURE (от 5 500 ₽), ATELIER (от 7 900 ₽).
- Форма: бюджеты 3 900–4 900 / 5 000–6 900 / 7 900–9 900 / 10 000+ ₽.
- Описание получателя стало необязательным, чтобы не затруднять оформление.
- Убрано ложное сообщение об отправленном и подтверждённом заказе: теперь клиент копирует заявку и отправляет её вручную в Telegram.
- Обновлены заголовки, навигация, метаданные и текст об условиях доставки.

## Как запустить
`npm install` затем `npm run dev`.
Для публикации: `npm run build` и загрузка на Vercel либо подключение Git-репозитория.

## Что важно перед реальными продажами
**На сайте нет серверной обработки заказов и приёма платежей.** Данные формы сохраняются локально в браузере клиента. Для автоматического оформления и учёта заказов необходим backend/CRM, платёжный провайдер, документы по персональным данным и проверенные условия доставки. В `src/config.ts` замените тестовый Telegram username на рабочий аккаунт магазина. Витрина содержит художественную графику и ориентировочные цены: поставьте реальные фотографии и утверждённый ассортимент. ИИ-генерация изображений и расчёт состава букета пока не реализованы.
